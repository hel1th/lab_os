
# OS_Lab4
## Антыгин Владимир 211
### Вариант 19

Необходимо создать динамические библиотеки, реализующие следующие функции:
Функция 1: Подсчёт количества простых чисел на отрезке [a, b] (cигнатура: int prime_count(int a, int b))
–	Реализация №1: Наивный алгоритм. Проверить делимость текущего числа на все предыдущие числа.
–	Реализация №2: Решето Эратосфена.

Функция 2: Подсчёт площади плоской геометрической фигуры по двум сторонам (cигнатура: float area(float a, float b))
–	Реализация №1: Фигура прямоугольник (S = a × b)
–	Реализация №2: Фигура прямоугольный треугольник (S = 0.5 × a × b)

Требуется использовать библиотеки двумя способами:
·	Программа №1: Статическая линковка на этапе компиляции
·	Программа №2: Динамическая загрузка во время исполнения с возможностью переключения между реализациями

Пользовательский ввод организован следующим образом:
·	Команда 0 – переключить реализацию (только для программы №2)
·	Команда 1 arg1 arg2 – вызов первой функции prime_count с аргументами
·	Команда 2 arg1 arg2 – вызов второй функции area с аргументами
